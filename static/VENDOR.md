# Third-party file in this directory

`chart.umd.min.js` is not my code.

- Library: Chart.js, version 4.5.1
- Source: https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.5.1/chart.umd.min.js
- Project: https://www.chartjs.org
- Licence: MIT, (c) 2014-2025 Chart.js Contributors

It is committed to the repository rather than loaded from a CDN so that the
container works with no internet access. It draws the latency chart on the
dashboard; nothing else in the project depends on it.
